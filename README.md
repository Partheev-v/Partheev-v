# 🚀 Featured Project

## 📡 TinyML-Based Predictive Energy Management and Service Prioritization in LoRa Disaster Mesh Networks

> An energy-aware disaster communication system using **ESP32, LoRa and TinyML** to improve communication reliability and manage limited node energy.

### 💡 Project Overview

The system is designed for **disaster and emergency communication scenarios**, where conventional communication infrastructure may not be available.

The network consists of:

- 👤 **S-Nodes** – User access and relay nodes
- 🏕️ **Base Node** – Base camp / central collection node
- 📡 **LoRa** – Long-range wireless communication
- 🧠 **TinyML** – Predictive energy management
- 🔋 **Energy-aware communication** – Efficient use of available node energy

A user sends information to an S-node, which can forward the information through other S-nodes until it reaches the base node.

The base node can acknowledge the received message and provide communication feedback.

### 🧠 TinyML Component

The TinyML model can use parameters such as:

- Battery percentage
- Solar input power
- Crank-generated power
- Message rate
- Number of active users
- Neighbor node count
- Node temperature
- Signal strength
